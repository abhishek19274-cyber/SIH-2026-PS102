# SIH Problem Statement 102 (MPLAD Audit System)
AI-Powered system for detecting anomalies, fraud, and inefficiencies in the MPLAD scheme.

## Quick Start (For the Team)
**1. Clone the Repo:**
`git clone https://github.com/abhishek19274-cyber/SIH-Problem-Statement-102.git`

**2. Backend Setup:**
1. `cd backend`
2. `python -m venv venv`
3. `source venv/bin/activate` (or `venv\Scripts\activate` on Windows)
4. `pip install -r requirements.txt`
5. `python app.py`

**3. Frontend Setup:**
1. `cd frontend`
2. `npm install`
3. `npm run dev`
